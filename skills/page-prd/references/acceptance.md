# 验收清单

按任务影响范围执行，不为仅改正文强行测试业务提交。浏览器操作不替用户领取、删除或提交真实任务。

## 正文与绑定

- 独立 Markdown 三个主节完整，字段、操作、只读统计、提示原文和异常说明可对照页面；未接入能力不写成已实现。
- 模块页面不缺失，目录名称与目标页一致，二/三/四级归属来自实际入口；静态路径优先，未知路由不误匹配。
- 保留全部无关正文和历史；“正式维护、不新增修订”同时满足。
- `check-manifest.mjs` 通过；仍需检查真实路由、文案及业务含义。

## 浏览器

- 用原业务地址与原鉴权访问。需要用户登录时明确提出，不绕过登录。
- 默认与收起后业务页面完整显示，右侧透明入口可拖且拖动不误展开；业务页面无注入编号、红框和残留分隔。
- 打开文档不重建业务组件；独立查看其他 PRD 不改业务路由、query/hash、草稿、滚动或工作台样本。实际导航恢复跟随。
- 目录单行、省略提示及拖动调宽；修订点击独立显示，不挤占正文阅读。
- 正文 Enter/Shift+Enter、输入法、编辑/完成、自动保存与刷新回显。失败、409冲突和快速切页不覆盖或丢输入；无保存成功不能显示已保存。
- 图表实时预览与错误禁止应用，图片上传/引用/删除、阅读放大按实际支持范围验证。
- 评论默认隐藏，可按需演示批注、回复、解决；没有后端一直明确演示状态，不称多人共享。

## 发布和导出

- 相关格式、lint、类型、单测及构建按项目现有命令执行；未运行的明确说明。
- 构建包含绑定正文、相对图片和图表依赖，生产正文不可编辑、不请求本地或mock写接口；子路径部署资源正确，原业务链接不改。
- 按需导出核对模块范围、父子顺序、标题、单页与完整模块区别；保留图表源码、相对图片及历史，导出不改源文件。
- 合并后正文与页面同版本；共享评论数据不因发布静态资源丢失。

## 技能包维护

运行 `node --test tests/*.node.mjs`；检查所有相对引用可解析、无本机绝对路径、个人样例、备份或 node_modules。在临时目录验证首次安装、重装备份、符号链接保持及 ZIP 内容一致；不在测试时改实际已安装技能。
