# 接入已有项目

## 优先复用

先搜索现有 manifest、documents、PRD 宿主和构建集成。若已有本项目新版，只补正文与绑定，不复制本包参考实现覆盖已确认组件。

`assets/integration-source/` 是本轮已确认 Vue/Vite 架构的参考源码，保留原相对目录，清除了业务文档及评论样例，提供两份虚拟页面文档以展示结构。它不是通用组件包，安装技能不自动写入项目；首次接入时逐个审查并适配，其他框架按行为契约实现。

| 参考路径                           | 用途与需适配的内容                                                                             |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| `src/components/PagePrd/index.vue` | 宿主包裹原 RouterView 一次，不给组件增加随路由变化的 key；适配已有 i18n 键、设计令牌和字体基准 |
| `src/components/PagePrd/routes.ts` | 读取 manifest 判断是否已绑定；不要注册业务路由                                                 |
| `designs/prd-review-v1/`           | 文档 UI、Markdown 转换、保存状态、图表及评论演示；换成真实页面清单，保留原有正文               |
| `scripts/page-prd-integration.ts`  | Vite 本地资源处理器与静态构建；适配根目录、资源前缀及 Mermaid 安装位置                         |

## 宿主与资源

1. 在现有 App 或合适的布局层挂一个宿主，内部 slot 保留原页面，PRD iframe 仅加载文档。不要再在文档框内加载第二份业务页。验证全屏登录与独立工作台也无额外留白。
2. 宿主以 `import.meta.env.BASE_URL` 解析文档入口，消息包含真实 Router path。只接收同源、来自当前文档窗口且类型在白名单内的消息；目录不调用 router.push。
3. 开发与发布使用同一文档 UI。开发服务提供受限文件读写；发布仅静态资源与只读 `runtime.editable:false`。文档失败不能阻止业务页面；按需加载且可重试。
4. 入口按已有 CSS 变量适配。参考源有本项目 rem 字号和 i18n `pagePrd.*` 键，其他项目不得照搬失效字号或未定义翻译。参考位置偏好 key 可按项目区分。

## 本地文件服务

参考 `server.mjs` 保留了历史独立调试入口，仅作源码证据；正式接入由 Vite 内部中间件驱动 `createReviewServer`，不要启动新端口或使用其兜底业务代理。

- 参考源码允许来源仍为 `127.0.0.1:3000/4311`，迁入其他端口、localhost 或部署前缀时必须改为目标项目明确的本地同源白名单，不使用通配来源。参考返回的文件路径前缀也要随目标目录改正。
- 仅读写登记 id 对应的 `documents/<id>.md`；创建新文档后重启开发服务使白名单更新。正文限制、文件版本校验、同文件串行保存、图片类型/大小及文件头校验保留。
- 生成 manifest 的本地 `runtime.editable:true`；生产不发布写入处理器。不要把 `/documents` 或 `/images` 追加到业务代理，也不使用通用业务 mock 接口保存 PRD。
- 静态资源及上传图片白名单与实际文件一致；不开放遍历任意文件。不要将保存服务暴露到测试环境。

## 构建

将 manifest、绑定正文内容、样式、浏览器脚本、图片与按需图表引擎输出到同源静态目录。参考实现输出 `__page-prd/`，保留已部署的业务地址及 base。浏览器 `.mjs` 发布为 `.js` 时，连同 Mermaid 传递依赖的引用一起改写，不能仅改入口。

参考实现需要 Vue 3、Vue Router、vue-i18n、Vite 和 Mermaid；不随技能捆绑 node_modules，不自动安装依赖。目标项目已有依赖则复用，缺少依赖按项目规则说明用途和成本后确认。

## 已知范围

轻量 Markdown 转换覆盖段落、换行、标题、加粗、列表、表格、代码块、图片，不是完整 CommonMark 编辑器；复杂格式用源码并验证往返。浏览器下载当前单页，模块导出用技能脚本。评论演示未接共享后端。参考源不自动追加修订，按用户本轮要求维护 manifest。

安装技能、接入参考源码和迁移旧文档是三个不同动作；只收到安装请求时不执行后两者。
